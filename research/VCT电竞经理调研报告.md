## 0. 一句话结论

这是一款**完成度惊人的人工制作 FM（足球经理）式无畏契约战队经理游戏**：以真实 VCT 生态数据（vlr.gg / Liquipedia）为底座，内含逐回合的比赛模拟引擎、跨赛季的选手成长与老化、带谈判博弈的转会市场、联盟经济与经理人生涯。单人开发者作品（"猪之家"，爱发电 `ifdian.net/a/pighome` 付费支持），纯前端 + localStorage 存档，无后端。搜索引擎未收录，属小众社区作品。

**对我们的启示**：它的护城河是"真实数据管线 + 模拟深度"，短板在"引导/可视化/单局体验/长线目标感"。做更好的版本应保留其数值骨架思路，重做体验层。

## 2. 核心玩法循环

```
┌─────────────────────────────────────────────────────────┐
│  开局：名字+年龄(影响成长) → 随机3选1出身 → 8点天赋分配   │
│        → 按声望选择愿意雇佣你的俱乐部(次级→一级)          │
└─────────────────────────────────────────────────────────┘
            ↓
┌─────────────────────────────────────────────────────────┐
│  回合制推进：赛季中 1 天=1 回合(行动力2点/天)             │
│             空档期 1 周=1 回合(行动力4点/周)              │
│  行动力花在：报价/问价/商务/约训练赛/换教练/挂牌/解约      │
│  不花在：首发/战术/训练安排                               │
└─────────────────────────────────────────────────────────┘
            ↓
┌─────────────────────────────────────────────────────────┐
│  每回合可做：排训练(7天/轮) · 调整每图预案(英雄+滑杆)     │
│  · 转会谈判 · 赞助/商务 · 约训练赛 · 处理事件(生日/矛盾)  │
│  → 推进时间：AI 世界同步演算，训练赛自动打完              │
│  → 我的比赛：赛前(对手情报+BP+每图预案) → 观战/快进       │
└─────────────────────────────────────────────────────────┘
            ↓
┌─────────────────────────────────────────────────────────┐
│  赛季结构(365天)：季前(0-20) → Kickoff(21-62)            │
│  → Masters I(63-98) → Stage1(99-164) → Masters II(165-214)│
│  → Stage2(215-280) → Champions(281-322) → 休赛期(323-364) │
│  生涯最长 10 个赛季；第 5 赛季末有「五年之约」结局分支     │
└─────────────────────────────────────────────────────────┘
```

**页面结构**（12 页）：俱乐部（总览/阵容/战术/训练）· 经营（转会/转会新闻/商务/财务）· 赛事（赛程/积分榜）· 生涯（经理/成就/资料库）· 系统（存档）。顶栏常驻：日期、赛段、资金、行动力、董事会信任、下一场倒计时。

**赛制还原度**（2026 抽签版）：
- Kickoff：12 队三败淘汰，上届 Champions 四强轮空胜者组第二轮
- Stage 1/2：Alpha/Omega 双组（按 Kickoff 名次分六档抽签），Stage 2 有"交换池重抽"（1/2、3/4、5/6 名池互换组别）
- Masters：瑞士轮逐轮抽签 + **赛区冠军自选八强对手**
- Champions：四档小组 + 八强抽签（小组第一抽别组第二、同组回避、胜者组决赛前不重赛）
- **轮到玩家的抽签会停下让玩家亲手抽**（把 RNG 仪式感做成了玩法）
- 另有 2023/2024/2025 历史档（2023 为 LOCK//IN 单国际赛制）
- 次级联赛：两个赛段，冠军通过 Ascension 升入 VCT

## 3. 比赛模拟引擎（核心数值，已完整还原）

### 3.1 选手有效能力

```
有效能力 = overall × (1 + (form-70)×0.0028 + (morale-70)×0.0016 − fatigue×0.0016 − [带伤0.22])
状态区间 30-99，士气 10-100，疲劳 0-100
→ 满状态 vs 零状态差距约 ±8%（form）±9.6%（morale），疲劳最高 -16%
```

### 3.2 团队强度（每张图独立计算）

```
base = Σ(首发五人有效能力 × 权重[1.24, 1.10, 1.00, 0.90, 0.76]) / Σ权重   ← 明星倾斜
atk = base + igl修正 + 化学反应 + 教练 + 版本强度 + 图池熟练 + 道具战术 + style克制 + 对手针对 + 短人惩罚 + familiar + (aim-65)×0.05
def = 同上 + (awareness-65)×0.05 + 1.6      ← 防守方固有 +1.6 优势
midRound = (adaptability-50)×K×0.05 + igl×0.06 + (clutch-65)×0.05 + styleMid + matchupMid
```

各项修正系数（全部还原）：

| 修正项 | 公式 | 量级 |
|---|---|---|
| IGL | (igl属性-60)×0.09，无 IGL 固定 -4 | ±3.6 |
| 化学反应 | ((teamwork+comm)/2 + (chem-基准)×0.18 - 65)×0.07 | ±2.4 |
| 教练 | (coach战术-60)×0.05 + 经理战术技能加成 + 分析师(opponent专精)×2.4 | ±2 |
| 版本/pick | 阵容英雄 vs 当前 patch meta（版本、地图适配、counter 三项） | 动态 |
| 图池 | (mapPref-50)×0.07 | ±3.15 |
| 道具 utility | style 对位 + (avg utility-65)×0.05 + 分析师(economy)×1.8 | ±2 |
| style 克制 | 团队风格（由英雄组合推导）vs 对手风格的相性表 | 动态 |
| 缺人 | 每少 1 人 -18 | -90~0 |
| 熟悉度 | 英雄熟练度集合函数 | 动态 |
| 赛前针对 | 侦察对手后准备的加分 | 动态 |

### 3.3 回合胜负（logistic）

```
m = (攻方atk + buy修正 + 暂停喊话修正 + 每图随机swing) − (守方def + …) + 落后方追分加成(0.35×midRound)
P(攻方胜) = 1 / (1 + exp(−m / 30))     ← 缩放常数 30，swing σ=6
```

- 12 回合攻防换边，先到 13 且领先 2（有 full24 练习模式），25 回合起交替进攻的无限加时
- **经济系统**：起始 $800；≥3900 买枪，≥2200 有 55% 概率强起；eco -15 / force -6.5 / full ±0 的战力修正；胜 +3000+200×对方存活，负 +1900+连败补偿(≤2×500)+200×己方存活，上限 9000
- **暂停喊战术**：每图 2 次暂停，效果持续 3 回合；rush = 攻 +2.4/守 -1.6，steady = 攻 -1.2/守 +2，focus（指定选手击杀权重 ×1.55）
- **击杀分配**：进攻方权重 = (42+(aim×0.55+reaction×0.3+clutch×0.15)×0.78)×位置系数 × (有效/面板)²；防守方权重 = (120−awareness×0.35−clutch×0.2)×位置系数；首杀权重 = 位置系数(决斗2/先锋1.3/自由1/哨卫0.6/控场0.5)×aim/60
- **位置系数**：决斗者输出最高（1.08/1.28）、控场哨卫偏低（0.93/0.88）——位置分工直接写进数学
- ACS = 伤害/回合 × 1.45（贴合真实 ACS）
- MVP = 全场 ACS 最高 + 胜方 +18 加成
- 高光系统：ACE、四杀、1vX 残局（clutch 加权）、5 连胜、赛点、翻盘（半场≤3 分逆转）、eco 局爆冷、零封——生成解说式文本，观战时逐回合播放

### 3.4 BP（Veto）

- BO1：交替 6 ban；BO3：ban,ban,pick,pick,ban,ban（胜者组上来的一方有优先权）；BO5：2 ban + 4 pick
- AI 决策：ban 掉（对手图池熟练 - 己方熟练）最大的图，pick 己方熟练最高的图，各带 ±6 随机噪声
- 玩家可提前设置 vetoPlan 或手动 BP；决胜图随机

## 4. 选手养成与状态系统

### 4.1 八维属性与 overall

`aim / reaction / awareness / utility / clutch / teamwork / communication / igl`（0-99，由真实数据分位映射），overall 由属性加权合成并受潜力上限约束。

### 4.2 训练系统（7 天/轮）

- **主训练三选一**：
  - 跑图：地图熟练度 +2/周（上限 95）、阵容熟练度 +12、协同 +9、意识 +5 经验；**四周没练没打的图每周 -0.6 衰减（最低 50）**
  - 教练复盘：意识 +6、沟通 +3（×教练战术系数）；只有 IGL 获得"指挥"经验（一轮约 +30，4 轮 +1 指挥属性，指挥越低涨越快——追赶机制）
  - 练英雄：每队每周最多 5 人，熟练度 +4.2/周；34 解锁入英雄池，练满 100 成为本命，**练满非本位置英雄会解锁兼任位置（变自由人）**
- **经验→属性**：攒满 100 点经验 +1 属性，单次收益公式：

```
xp = rand(7,16) × 年龄系数(≤20:1.35/≤23:1.1/≤26:0.8/其他0.45) × 疲劳系数(>70:0.5/>45:0.8/1)
     × (0.75+士气/200) × (1 + 教练dev加成 + 设施加成) × 成长空间(|potential-overall|/12, 截断0.25~1.6)
     × 商务占用惩罚 × 经理训练技能 × 青训加成 × 复出名气系数
```

- **休息**：疲劳 -18~30（×医疗技能），士气 +0.5~2.5
- **双人组（duo）特训**：两人 teamwork/communication/reaction 经验 + 羁绊值
- **突破系统**：安排选手休假赌潜力上限，成功率制（breakChance），成则 potential +N，败则 -6 士气但保留下次契机
- 每周结算：form 向 70 回归（±0.06×周 ±3.5 随机）、士气向基准回归、疲劳自然恢复（×医疗技能）

### 4.3 伤病

```
周检概率 = (0.001 + max(0,fatigue-45)/55 × (0.018 + max(0,age-27)×0.002)) × 近伤0.25
赛后概率 = (0.002 + max(0,fatigue-40)/60 × 0.026) × (图数/3)
→ 老将+疲劳是主要风险源；医疗技能直接乘在概率上；理疗师可 -35 疲劳/-30% 伤停时间
```

### 4.4 心理层（该游戏深度的重要来源）

- **士气**（10-100）：胜负 ±1~5、生日祝福 +2/礼物 $200 +5/派对 $2500 全队 +2 并加羁绊
- **信任（trust）**：俱乐部与选手之间的关系值，影响续约谈判
- **不满（grievance）**：承诺角色未兑现每周 +7（star）/ +4.5（starter），兑现则 -3；>40 会挂牌逼宫；>55 有 25% 概率考虑离队
- **忠诚（loyalty）/野心（ambition）**：转会谈判的权重项
- **宿敌系统**：国际赛战绩累计"关注度"（heat），≥75 被重点针对——被打服的队伍会在休赛期获得额外预算针对补强，侦察读盘（对手每图战术偏好）按赛季半衰
- **退役与劝留**：老将宣布退役后可谈：加薪 30%（谈判技能定成功率）/ 转替补 / 挂牌 / 办退役仪式 / 深谈，各有机率公式；明星退役有告别卡与生涯回顾

## 5. 转会市场（谈判博弈模型）

### 5.1 基础规则

- **名单上限 7 人（含替补），最低 5 人**；转会窗一年 4 个：季前 0-20、63-90、165-198、休赛期 323-363
- 身价 = 基础值(overall/潜力/年龄) × (1 + 合同年×0.18) × (挂牌? 0.75)
- 转会费接受度：≥解约金必成；≥身价必成；70%-100% 线性概率；<70% 拒绝
- 解约：赔付剩余合同的 40%；卖出后原队 <5 人会自动紧急签自由人
- noPoach（抢人保护条款）、releaseClause（解约金，触发后原队无权拒绝）

### 5.2 报价谈判（对选手）：logistic 模型

```
score = (薪资/期望-1)×60 + 签字费/期望×26 + (奖金分成%-10)×0.9
      + 角色承诺差值(升级×11/降级×16) + (队伍声望-现队声望)×0.9
      + 级别差(升+18/降-22) + 忠诚修正(±) + 解约金+7 + 不满×0.25
      + 野心修正 + 替补身份(+14 想走) + 经理谈判技能×30 + 经理声望(-8~+20)
P(接受) = 1/(1+exp(-score/14))；薪资<期望70% 直接判定"缺乏诚意"
```

合同可谈条款：薪资/年限(1-4)/签字费/**奖金分成 0-35%**（奖金到手时按人头扣除）/承诺角色（核心/首发/轮换/替补）/解约金/noPoach。游戏把每个低分项翻译成人话反馈（"他认为这支球队不如他现在的平台"），并给出接受概率评级（很可能接受/有机会/希望不大）。

### 5.3 AI 生态

- AI 队会**报价挖你的球员**（7 天答复窗口），触发解约金时你无权拒绝
- 挂牌逻辑：阵容过剩（+22%/天判定）、不满>40（+30%）、合同年替补（+15%）、29 岁替补（+12%）；下架逻辑反向
- AI 之间的转会完全自动演算，形成动态市场（实测 20 天内出现 MIBR 报价我方 nnono $272K、C9 关注、bang/kiNgg 等挂牌的活市场）
- 侦察系统：对目标选手做 scouting 后才能看到潜力确切值（眼光低只显示区间）

## 7. 经理人生涯（元游戏）

- **开局**：年龄 slider（青年=成长最快声望最低）、随机 3 选 1 出身（投资人 $900K 启动资金+商务强 / 数据分析师 眼光训练强更衣室弱 / 退役职业选手 声望+12 / 主播名人 / 青训教练 / 别的项目转来 等，各 2 强 1 弱）、8 点天赋自由分配 8 技能（训练/谈判/战术/眼光/体能/商务/更衣室/带新人，每点+5 上限 90）
- **声望门槛**：声望决定哪些队雇你（每赛区最强 3 队开局锁死）；三连冠/打满十年/声望 90 解锁任意选队
- **董事会**：每赛段按实力排名布置目标（达成 +6~16 信任，未达 -2~-18）；≤20 信任警告，警告后连续 2 赛段未达标或信任≤6 **下课**（gameOver，有统计结算页）
- **经理生活模拟**：个人钱包、饱腹（-4/天）、心情（-1/天），影响本队训练收益与谈话成功率（最多 ±8%）；吃饭/休息/娱乐动作 + 自动补给预算——用极低的操作成本提供了"人"的代入感
- **跳槽**：主动申请（成功率 = 0.1+声望差×0.011+荣誉×0.03+战绩差队加成，谈判技能放大）、被挖角、续约谈判（董事会按信任度/荣誉/在手 offer 议价）
- **经理技能实时生效**：训练×收益、谈判×转会续约成功率、战术×比赛加成、医疗×伤病疲劳、更衣室×士气不满、带新人×U23 成长、商务×赞助、眼光×潜力侦察
- **成就系统** + 荣誉陈列 + 十年生涯成就 + 「五年之约」中期结算分支（收官或继续）
- **娱乐模式（beta）**：+200 退役明星与主播（TenZ、Sacy、yay、tarik…）只愿为玩家复出，带直播合同/人气/训练少等专属机制

## 8. UI/UX 实测观察（优点与短板）

### 做得好的

1. **信息密度与可读性平衡**：总览页一屏给齐"下一步该干什么"（任务清单卡片化：训练没排/窗口要关/战术没定/商务没排）
2. **文案是灵魂**：所有系统都有性格化中文叙事（拒绝你的 scouting："快要和我们打正赛，不想暴露战术"）；AI 行为全部有理由
3. **把不确定性做成仪式**：亲手抽签、亲手开卡（同站开瓦包）、观战模式的逐回合播放+暂停喊战术
4. **透明数值**：训练页直接写 "+N 都是经验，攒满 100 才 +1"；谈判给概率评级和最低分项反馈——玩家永远知道为什么
5. **真实数据信任感**：英雄出场率、对手阵容预测（"VLG 这张图大概率是双哨卫，节奏放慢；冲两个哨卫的布置就是送"）都来自真实数据推导
6. 主题三配色（深/浅/米）、音乐播放器、移动端适配（viewport-fit=cover）

### 短板（= 我们的机会）

1. **单局比赛体验弱**：观战是文本流+简易演算动画，无地图可视化（没有点位/击杀地图/经济条 UI），高光只有文字——电竞游戏的"看比赛"爽感缺失
2. **引导不足**：17 页教程弹窗一次性轰炸；机制藏在"机制说明"按钮里；新手第一周动作缺少智能提示的优先级
3. **可视化贫乏**：选手全靠文字表格+头像，无雷达图对比、无历史曲线、战术板无图示
4. **节奏单调**：空档期"推进 7 天"一键后大量等待，中期事件密度不足，容易进入"点按钮看报告"的机械循环
5. **性能**：纯前端单线程演算全世界，观战模式下在低配/嵌入式浏览器会崩（实测 IAB 内崩溃两次）
6. **无社交/分享**：成就与冠军无法生成分享图；存档仅本地
7. **音频单薄**：只有 BGM，无比赛音效/解说
8. **数据为静态快照**：2026 档为一次性生成（真实数据截至抓取日），无赛季中动态新闻源

## 9. 做"更好的版本"的设计建议（基于以上调研）

1. **保留其数值骨架**：这套 logistic 比赛引擎、分位映射真实数据、8 维属性+状态三角（form/morale/fatigue）、谈判 logistic 模型经过实测是自洽且耐玩的，值得借鉴甚至复用思路
2. **重做比赛表现层**：2D 地图回放（回合事件流 → 点位动画）、经济条、击杀 feed、赛后战术热图——这是最大差距点，也是"电竞感"的来源
3. **事件驱动代替日历驱动**：把"推进 7 天"改为事件卡流（训练赛邀请/选手矛盾/网暴/版本改动爆料），保持推进效率的同时制造决策密度
4. **新手体验**：分步解锁系统 + 首周"教练建议"AI 提示（基于当前状态给出 3 个最优动作）代替 17 页弹窗
5. **强化长线目标**：经理生涯按"执教履历页"组织（冠军墙/门下选手/名场面收藏），赛季末生成可分享的赛季海报
6. **考虑把世界演算放 Worker/服务端**：解决性能与未来多人对抗（经理人 vs 经理人联赛）的可能
7. **数据管线产品化**：如果做同样真实数据的游戏，需要 vlr.gg/Liquipedia 的定期抓取+分位映射流水线（它的 8 维分位映射+英雄池出场率是数据护城河）
