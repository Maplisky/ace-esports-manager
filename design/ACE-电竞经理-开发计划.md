## v1.0 收尾排期（发布线 v1.0-8..-14，2026-10-15 二次重排：纳入设计咨询结论）

原则：v1.0 只做 GDD §13 对 v1.0 里程碑的承诺项 + 发布信任项 + **留存与增长钩子**（教学局骨架、回放链接——web 发布零预算时的生死项，GDD §17 v2.5）；v0.x 欠账入 v1.1-v1.5 补账线，不阻塞发布。

1. **v1.0-8 对局战术交互**（规模 M）
   - 内容：情境化暂停战术菜单（防守：多人抱团前压 / 131 快速回防 / 放点打回防 / 双哨位蹲通道；进攻：Rush 集火 / 假打转点 / 慢速默认+中局变奏 / 大招速攻——按攻防方×地图点位×经济×大招状态过滤）+ 暂停预期提示精度（情报等级 × 比赛型教练数值）+ IGL 场上阅读（第 7/14 回合，建议质量 = IGL 属性×情报×教练加成，高配近乎必中对策/低配可能误判；采纳或无视）+ 组合战术（≥2「核心」档就绪才解锁大招速攻）；选秀权可交易（截止日内选秀签入谈判筹码）；**IGL 自信误判呈现**（低配 IGL 的错误建议同样自信样式高亮，赛后总结页可回看「当时 IGL 读了什么」——GDD §5.4 v2.5）
   - 验收：菜单选项经引擎既有 tactic 标识（atk:rush:A / def:stack:B）实际改变后续回合模拟；**不操作暂停菜单/不采纳建议时比赛逐位与现状一致（回放红线，测试锁死）**；大招门控读 end.ults 快照；误判呈现抽检截图留档；三轮检错零检出
2. **v1.0-9 存档信任 + 性能基准**（规模 M）
   - 内容：§11.4 全量——3 手动槽+自动档+每日轮换备份+导出/导入 JSON（migrations[] 既有，导出「永远可用」是信任条款）；§11.3 基准自动化（node:test：推进 1 天 <50ms / 单图模拟 <30ms / 存档 <4MB 硬上限 12MB 归档）
   - 验收：**旧单一 `autosave` 键无损迁移进多槽结构（golden save 回归必须含旧结构档）**；导出 JSON 再导入后世界逐位一致；性能基准连续三次本机跑绿
3. **v1.0-10 成就（剧本路径）+ 移动端伴侣模式**（规模 M）
   - 内容：成就按四条剧本路径组织（重建者 / 王朝缔造者 / 青训教父 / 雇佣兵，各 3-5 成就 + 1 史诗，「一城终身」归青训教父线）+ 跨路径通用层（首胜/首冠/大满贯/十年执教），挂名人堂数据源（career 账本 / retireLog / lastDraft 现成），挑战剧本进度占位复用同判定器；移动端收窄为**伴侣模式**——收件箱/推进/课表/市场四场景 375px 可用，比赛观看与战术页桌面优先，不做全量 parity（GDD §18-8 v2.5）
   - 验收：四路径各至少一成就在测试档可解锁（判定只读既有账本 + 增量 state migrate `??=`）；预留「教学局不计成就」口径（§3 scripted 标记）；伴侣模式四场景抽检清单留档；三轮检错零检出
4. **v1.0-11 开局引导骨架**（规模 M；v1.2 完整版的前移子集）
   - 内容：首场教学脚本局（scripted 优势局 + 强制观战 3 回合 + 暂停喊一次战术）+ D1-D20 系统解锁表（解锁即 30 秒场景任务，非说明弹窗）；完整捏人/引导任务清单仍留 v1.2
   - 验收：教学局 scripted 标记不计生涯统计与成就（§3/§5.1 口径）；**旧档（已过 D20）加载即全解锁、无感知差异**；同 seed 世界生成逐位一致；三轮检错零检出
5. **v1.0-12 分享钩子：回放链接 + 匿名化开关**（规模 S）
   - 内容：MatchRecord + seed 导出为 URL 参数（≤8KB），他人点开即看同一比赛的播放器（GDD §9.4）；导出带**匿名化开关**（真实选手名/队名→生成名替换，公开分享可控暴露面，GDD §14）
   - 验收：链接在干净浏览器打开可完整回放且逐位一致；匿名化导出物扫描无真实选手名字符串残留；链接只读既有 MatchRecord（不新增 RNG 调用）；三轮检错零检出
6. **v1.0-13 双端发布**（规模 S[Pages] / L[Steam]）
   - 内容：**阻塞于发布形态决策**——浏览器端 GitHub Pages 先行（vite `base` + 产物验证）；Steam 端（Tauri/Electron + Steamworks）待发布后自然流量信号再评估，不预先投入
   - 发布 DoD（浏览器）：生产构建 preview 冒烟——开新档推进一周 + 打一场 + 存/读/导出/导入全通；子路径资源加载正确；**分享链接实测**；PWA 离线可选
7. **v1.0-14 发布闸门**（规模 S~M）
   - 内容：九图目检（`/maps-preview.html` 逐图对照官方俯视图——除 Haven 外九图仅数值核验未目检）/ 完整 Mimosa 安全审计（pre-commit 的 library_source/callgraph 扫描不完整，**审计前勿宣称项目安全**）/ golden save 回归 + 同 seed 双跑 / **设计 playtest 协议**：三档难度各完整推进一个赛季——普通难度 t2 开局首赛季胜率 45-60%、全程无意外破产、HHI<0.18（自动测试既有）、首小时决策密度主观记录留档
   - 验收：目检记录/审计摘要/playtest 记录归档（本文档或 research/）；同 seed 双跑 diff = 0
