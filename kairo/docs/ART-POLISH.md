# 《VCT冠军经理》美术优化清单

对照对象：开罗软件官方截图四张（《温泉乡 2》标题画面、《世界俱乐部足球物语》赞助谈判、《电影物语》上映结算、《职业摔角物语》对阵板）+ Game Dev Story 界面惯例。
对照基准：本作 `m2/GrayBox.tscn`（当前实现）与 `m3/Theater.tscn`。
原则（立项 §7）：竖屏单手、像素对齐整数缩放、UI 代码绘制、程序化小人不进内核。

## 落地顺序建议

1. **第一批（纯样式，改动小收益大）**：A2 按钮样式、A3 数字描边、B3 资源条——一次改全站观感。
2. **第二批（结构）**：B1 三段式面板、C1 对阵板、D2 设施像素小图——需要新绘制/新组件。
3. **第三批（演出细节）**：C2 走路带、C4 结算窗、D1/D3/D4、E 组——打磨项。
4. 回归闸门每批后：双自检 + CS 118/118 + TS 201/201。

## 已达标项（无需改）

- 竖屏 720×1280 单手布局（§7 布局原则）
- 程序化小人 + 调色板换装 + 庆祝/阵亡梯度（§7 美术管线，m0 已验证）
- 像素整数倍缩放（default_texture_filter=0）
- 可跳过/加速的回放（Space 倍速 / → 跳图）
- 三槽存档 + 解锁节奏引导（§7 反馈原则部分达成）
